AI API 中转是放在桌面客户端和模型厂商之间的大模型网关。在 Cherry Studio 里接入 LingTrue 时，API 地址填根地址 https://www.lingtrue.com，API 密钥填 LingTrue 令牌，模型名填厂商模型 ID。这样一份配置就能用 OpenAI 兼容接口调用 GPT，并用同一把密钥调用 Claude API 模型，不必为每家厂商各申请一把 Key。

可复制配置：Cherry Studio 的 API 地址用 https://www.lingtrue.com（不要带 /v1）。OpenAI SDK 的 base_url 用 https://www.lingtrue.com/v1。模型名示例：gpt-4o-mini、gpt-4o、claude-sonnet-4-5-20251022。单价以 定价页 实时显示为准。

开始前准备什么

  • Cherry Studio 桌面客户端。设置入口是「设置 → 模型服务」。
  • LingTrue 令牌。在 注册 后，到 令牌管理 创建，密钥以 sk- 开头。
  • 若你已经按 AionUI 配置指南 接过 LingTrue，可以继续用同一枚令牌，不必另开账号。

配置步骤

1. 创建 LingTrue 令牌

  1. 打开 https://www.lingtrue.com/register 注册。
  2. 进入 控制台 → 令牌管理，点击创建令牌。
  3. 名称可写 Cherry Studio，创建后立即复制完整密钥。

令牌页如果出现 Cherry Studio 快捷按钮，会把根地址和密钥写入客户端，效果与下面的手填一致。没有该按钮时，按手动步骤配置即可。

2. 打开 Cherry Studio 的模型服务

  1. 启动 Cherry Studio，打开 设置。
  2. 进入 模型服务。
  3. 优先选择内置的 New API 条目。这是客户端用来连接 OpenAI 兼容网关的模板，账户和地址都填 LingTrue，显示名可以改成 LingTrue。
  4. 若当前版本列表里没有该项，点添加 自定义服务商，协议选 OpenAI 兼容，名称写 LingTrue。

3. 填入可复制的连接信息

字段 填写 说明
API 密钥 sk- 开头的完整令牌 只保存 LingTrue 令牌，不要填 OpenAI 或 Anthropic 官网密钥
API 地址 / Base URL https://www.lingtrue.com 根地址。Cherry Studio 会按协议自动补 /v1 或 /v1beta
不要填写 /chat/completions、# 路径由客户端拼接。末尾加 # 会关掉自动补路径，接 LingTrue 时不要加 
提供商: New API 或自定义 OpenAI 兼容服务商
名称: LingTrue
API 密钥: sk-your-lingtrue-token
API 地址: https://www.lingtrue.com

保存后看请求预览。正确结果应落到 https://www.lingtrue.com/v1/chat/completions。若变成 /v1/v1/chat/completions，说明 API 地址里多写了 /v1，改回根地址。

4. 添加模型并检测

  1. 点击获取模型列表。列表为空时改为手动添加，模型 ID 必须与网关一致，区分大小写。
  2. 打开该服务商右上角的启用开关。
  3. 选一个对话模型点检测。通过后回到聊天窗口，发送一句「用一句话介绍你自己」。

模型名示例：同一网关调用 GPT 与 Claude

LingTrue 对外是 OpenAI 兼容的大模型网关。Cherry Studio 里换模型只改模型 ID，Base URL 和 API 密钥保持不变。下表是文档中使用的标识，上线前请到 定价页 或 GET /v1/models 核对是否仍在提供。

用途 模型 ID 在 Cherry Studio 中怎么用

和代码里的 Base URL 不要混用

客户端和 SDK 对「Base URL」的切法不同。Cherry Studio 要根地址；OpenAI 官方 SDK 要带 /v1。下面这段代码用同一把 LingTrue 令牌分别请求 GPT 和 Claude，适合用来确认网关，而不是替代 Cherry Studio 的界面配置。 

from openai import OpenAI

client = OpenAI(
    api_key="sk-your-lingtrue-token",
    base_url="https://www.lingtrue.com/v1",
)

gpt = client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[{"role": "user", "content": "用一句话介绍你自己"}],
)

claude = client.chat.completions.create(
    model="claude-sonnet-4-5-20251022",
    messages=[{"role": "user", "content": "用一句话介绍你自己"}],
)

需要 Anthropic 官方 SDK 时，base_url 填 https://www.lingtrue.com，由 SDK 自己请求 /v1/messages。接口说明见 接入文档。更多代码示例见 3 分钟接入 AI API。

和「便宜接入」的关系

这里的便宜接入，指用一把 LingTrue 令牌按量调用 Claude 与 GPT，少维护多套官网账单。它不表示某一个模型一定低于官方牌价。各模型输入、输出单价会变，只以 https://www.lingtrue.com/pricing 当时显示的数字为准。怎么在网关和模型之间取舍，见 AI API 中转怎么选。

常见问题

Cherry Studio 的 Base URL 要不要加 /v1？

在 Cherry Studio 的 New API 或 OpenAI 兼容服务商里，API 地址填根地址 https://www.lingtrue.com，不要加 /v1，也不要加 /chat/completions。客户端会按协议自动补上 /v1 或 /v1beta。用 OpenAI 官方 SDK 写代码时，base_url 才写成 https://www.lingtrue.com/v1。

同一把 LingTrue 令牌能同时调用 Claude 和 GPT 吗？

可以。LingTrue 是 OpenAI 兼容的大模型网关，对话请求发到同一个 Base URL，用 model 区分，例如 gpt-4o-mini 与 claude-sonnet-4-5-20251022。Claude 也可以走 Anthropic 原生 /v1/messages，此时 SDK 的 base_url 填 https://www.lingtrue.com。

这样接入 Claude API 会不会更便宜？

便宜与否取决于具体模型和路由，本文不列单价。请打开 定价页 对照官方标价。页面上的数字会变，以定价页实时显示为准。

获取模型列表失败怎么办？

先确认 API 密钥是控制台复制的完整令牌（以 sk- 开头），API 地址是 https://www.lingtrue.com 且本机可以访问。仍然失败时，改为手动添加模型 ID，不要只依赖自动拉列表。余额不足或模型名写错时检测会失败，但密钥本身可能是有效的。

已经在 AionUI 里配过 LingTrue，Cherry Studio 还要新的 Key 吗？

不需要。同一枚 LingTrue 令牌可以同时用于 Cherry Studio 和 AionUI。两边都填根地址 https://www.lingtrue.com，差别只在客户端的设置入口。AionUI 的点击路径见 AionUI 配置指南。
