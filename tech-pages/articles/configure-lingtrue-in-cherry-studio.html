An AI API gateway sits between a desktop client and the model vendors. In Cherry Studio, point LingTrue at the root host https://www.lingtrue.com, paste a LingTrue token as the API key, and set the vendor model ID. One OpenAI-compatible setup then calls GPT and Claude API models with the same key, without a separate account at each vendor.

Copy-paste values: Cherry Studio API host is https://www.lingtrue.com (no /v1). The OpenAI SDK base_url is https://www.lingtrue.com/v1. Example model IDs: gpt-4o-mini, gpt-4o, claude-sonnet-4-5-20251022. Live prices are on the pricing page.

What you need

  • Cherry Studio for desktop. The path is Settings, then Model Provider.
  • A LingTrue token. Register, then create one under token management. The key starts with sk-.
  • If you already followed the AionUI guide, reuse that token. You do not need another account.

Steps

1. Create a LingTrue token

  1. Open https://www.lingtrue.com/register and create an account.
  2. Go to Console, then Tokens, and create a token.
  3. Name it Cherry Studio and copy the full key immediately.

If the token page shows a Cherry Studio shortcut, it writes the same root host and key into the client. Without that button, use the manual steps below.

2. Open Model Provider in Cherry Studio

  1. Launch Cherry Studio and open Settings.
  2. Open Model Provider.
  3. Prefer the built-in New API entry. That template connects an OpenAI-compatible gateway. The account and host are LingTrue; you can rename the provider to LingTrue.
  4. If that entry is missing, add a custom provider, choose the OpenAI-compatible protocol, and name it LingTrue.

3. Paste the connection values

Field Value Notes
API key The full token starting with sk- Use the LingTrue token, not an OpenAI or Anthropic dashboard key
API host / Base URL https://www.lingtrue.com Root host. Cherry Studio appends /v1 or /v1beta by protocol
Do not enter /chat/completions or a trailing # The client appends the path. A trailing # disables that, which LingTrue does not need 
Provider: New API, or a custom OpenAI-compatible provider
Name: LingTrue
API key: sk-your-lingtrue-token
API host: https://www.lingtrue.com

After saving, check the request preview. It should target https://www.lingtrue.com/v1/chat/completions. A path of /v1/v1/chat/completions means the host already included /v1. Change it back to the root.

4. Add models and test

  1. Fetch the model list. If it is empty, add model IDs by hand. IDs are case-sensitive and must match the gateway.
  2. Turn on the provider switch.
  3. Run Check on a chat model, then send a short message from the chat window.

Do not mix this host with the SDK Base URL

Clients and SDKs split the Base URL differently. Cherry Studio wants the root. The official OpenAI SDK wants /v1. This snippet calls GPT and Claude with one LingTrue token. It checks the gateway; it does not replace the Cherry Studio form. 

from openai import OpenAI

client = OpenAI(
    api_key="sk-your-lingtrue-token",
    base_url="https://www.lingtrue.com/v1",
)

gpt = client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[{"role": "user", "content": "Introduce yourself in one sentence"}],
)

claude = client.chat.completions.create(
    model="claude-sonnet-4-5-20251022",
    messages=[{"role": "user", "content": "Introduce yourself in one sentence"}],
)

For the official Anthropic SDK, set base_url to https://www.lingtrue.com so the SDK calls /v1/messages. See the API docs and the 3-minute quickstart.

What “cheaper access” means here

Cheaper access means one LingTrue token, billed by usage, for both Claude and GPT, with fewer vendor dashboards to keep. It does not mean every model is below the vendor list price. Input and output rates change. Use only the numbers on https://www.lingtrue.com/pricing. For the gateway-versus-model decision, read How to choose an AI API gateway.

FAQ

Should the Cherry Studio Base URL include /v1?

No. In the New API provider or a custom OpenAI-compatible provider, set the API host to https://www.lingtrue.com. Do not add /v1 or /chat/completions. The client appends /v1 or /v1beta. In the official OpenAI SDK, base_url is https://www.lingtrue.com/v1.

Can one LingTrue token call both Claude and GPT?

Yes. LingTrue is an OpenAI-compatible LLM gateway. Chat requests share one Base URL and select the model with model, for example gpt-4o-mini or claude-sonnet-4-5-20251022. Claude can also use the native Anthropic /v1/messages route; that SDK base_url is https://www.lingtrue.com.

Is Claude API access cheaper this way?

That depends on the model and the route. This page does not list unit prices. Compare the pricing page with the vendor list price. Those figures change; the pricing page is the source of truth.

The model list failed to load. What now?

Confirm the API key is the full console token (it starts with sk-) and the host is https://www.lingtrue.com. If the list is still empty, add model IDs manually. A failed check can also mean an empty balance or a wrong model name while the key itself is valid.

I already configured LingTrue in AionUI. Do I need a new key?

No. The same LingTrue token works in Cherry Studio and AionUI. Both use the root host https://www.lingtrue.com. Only the settings screens differ. The AionUI clicks are in the AionUI guide.
