AionUI 是一款强大的开源、跨平台 AI Agent 可视化管理桌面工具（GitHub 30k+ Star）。它提供了统一的图形界面来管理多个 AI 智能体和大语言模型。本文将手把手教你如何在 AionUI 中配置 API 中转站，通过 LINGTRUEAPI 统一网关访问 GPT、Claude、Gemini 等 AI 模型。

什么是 API 中转站？API 中转站（也称 API 网关或转发站）是位于你的客户端应用和上游 AI 模型提供商之间的服务。它提供统一计费、智能路由、成本优化等功能，让你通过一个 API Key 即可访问 35+ 种模型。LINGTRUEAPI (www.lingtrue.com) 就是这样的服务。

前置准备

  • 已安装 AionUI — 从 GitHub Releases 下载安装（支持 Windows、macOS、Linux）
  • 拥有中转站的 API Key — 在 LINGTRUEAPI 控制台 创建令牌

第一步：从 LINGTRUEAPI 获取 API Key

  1. 访问 www.lingtrue.com/register 注册免费账号
  2. 登录进入控制台
  3. 进入 令牌管理，点击 "创建令牌"
  4. 为令牌起一个描述性名称（如 "AionUI"）
  5. 点击 复制 按钮，将 API Key 复制到剪贴板

你的 API Key 格式类似：sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

提示：配置前可以先访问模型定价页面，查看所有可用模型及其费用。

第二步：打开 AionUI 的 LLM 配置

  1. 启动 AionUI 应用
  2. 点击左侧或顶部菜单中的 设置（齿轮图标）
  3. 进入 LLM 配置（或"大模型设置"/"Model Settings"）
  4. 点击 "添加模型"

第三步：配置自定义平台

在"添加模型"对话框中，按以下步骤配置：

3.1 选择平台

在平台下拉菜单中选择 "自定义"（Custom）。此选项支持任何 OpenAI 兼容的 API 接口，正是 LINGTRUEAPI 所提供的。

3.2 填写连接信息

配置项 填写内容 说明
API Key sk-xxxx（你复制的密钥） 粘贴第一步中获取的令牌
API 请求地址（Base URL） https://www.lingtrue.com 大多数模型不需要添加 /v1 后缀
模型名称 如 gpt-4o 填写准确的模型标识符

3.3 重要提示：Base URL 格式

Base URL 的格式取决于你要配置的模型类型：

  • 大多数模型（GPT、Claude、Gemini、DeepSeek 等）：
    使用：https://www.lingtrue.com（不带 /v1）
  • Codex 模型专用：
    使用：https://www.lingtrue.com/v1（带 /v1 后缀）
为什么有区别？Codex 使用了略有不同的 API 路径结构。如果你不确定，先不加 /v1 试试——绝大多数模型都适用。

第四步：选择模型

LINGTRUEAPI 支持 35+ 种模型。以下是在 AionUI 中可配置的热门模型：

推荐模型

模型 适用场景 模型 ID
GPT-4o 通用场景，速度快、能力强 gpt-4o
GPT-4o Mini 性价比高的日常任务 gpt-4o-mini
Claude Sonnet 4 编程、深度分析、写作 claude-sonnet-4-20250514
Claude Opus 4 最强推理能力模型 claude-opus-4-20250514
Gemini 2.5 Pro 超长上下文、多模态 gemini-2.5-pro
DeepSeek V3 性价比极高的编程与推理 deepseek-chat

查看完整模型列表和实时定价，请访问 LINGTRUEAPI 模型定价页面。

第五步：保存并测试

  1. 点击 "保存" 存储配置
  2. 返回 AionUI 主界面
  3. 在模型下拉菜单中选择刚刚配置的模型
  4. 发送一条测试消息（如"你好，能听到我吗？"）
  5. 如果收到回复，配置就成功了！

进阶：多 Key 轮换

AionUI 支持 API Key 轮换以实现负载均衡和容错。配置方法：

  1. 在 API Key 输入框中，输入多个 Key，用逗号分隔：
sk-key1,sk-key2,sk-key3

AionUI 会在遇到限流（429）或认证失败（401）时自动切换到下一个 Key，失败的 Key 会有 90 秒的冷却期。

进阶：配置多个模型

你可以添加多个模型配置，通过同一个中转站访问不同的 AI 模型：

  1. 对每个要添加的模型重复第二到五步
  2. 使用相同的 API Key 和相同的 Base URL
  3. 只需更改每次的模型名称即可

这样，你就可以在 AionUI 的模型选择器中直接切换 GPT-4o、Claude、Gemini 等不同模型——全部通过一个 LINGTRUEAPI 账号驱动。

常见问题排查

问题 解决方案
模型列表为空 检查 API Key 是否有效，Base URL 是否正确
认证失败（401） 确认 API Key 未过期；如需要可重新生成
连接超时 检查网络连接，确保能访问 www.lingtrue.com
限流错误（429） 稍等片刻后重试，或配置多个 Key 进行轮换
模型无响应 确认模型名称正确（区分大小写）；检查账户余额
Codex 模型不工作 确保使用 https://www.lingtrue.com/v1（带 /v1）

总结

在 AionUI 中配置 API 中转站非常简单：

  1. 从 www.lingtrue.com 获取 API Key
  2. 在 AionUI 设置 → LLM 配置中添加自定义模型
  3. 填入 API Key + Base URL（https://www.lingtrue.com）+ 模型名称
  4. 保存并测试

配置完成后，你就可以通过 AionUI 访问 35+ 种 AI 模型，享受智能路由、成本优化和统一计费体验。更多指南请访问我们的技术博客，或前往关于页面了解更多关于 LINGTRUEAPI 的信息。
