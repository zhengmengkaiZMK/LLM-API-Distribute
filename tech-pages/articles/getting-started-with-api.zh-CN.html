欢迎使用 LINGTRUEAPI！本指南将带你从零开始，3 分钟内完成 AI API 网关的接入。

第一步：创建账号

访问注册页面创建免费账号。注册即送免费额度，可立即开始使用。

第二步：生成 API Key

登录后，进入控制台的令牌管理页面，点击"创建令牌"生成你的通用 API Key。

你的 API Key 适用于所有 35+ 种支持的模型——无需为不同提供商创建不同的密钥。

第三步：发起第一个 API 请求

LINGTRUEAPI 完全兼容 OpenAI SDK 格式。只需替换 Base URL 和 API Key： 

curl https://www.selfagent.ai/v1/chat/completions \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-4o",
    "messages": [{"role": "user", "content": "你好！"}]
  }'

第四步：在常用 SDK 中使用

Python（OpenAI SDK）

from openai import OpenAI

client = OpenAI(
    api_key="YOUR_API_KEY",
    base_url="https://www.selfagent.ai/v1"
)

response = client.chat.completions.create(
    model="gpt-4o",
    messages=[{"role": "user", "content": "你好！"}]
)
print(response.choices[0].message.content)

Node.js

import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: 'YOUR_API_KEY',
  baseURL: 'https://www.selfagent.ai/v1'
});

const response = await client.chat.completions.create({
  model: 'claude-sonnet-4-20250514',
  messages: [{ role: 'user', content: '你好！' }]
});
console.log(response.choices[0].message.content);
