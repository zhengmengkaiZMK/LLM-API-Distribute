# 特定服务条款

**生效日期：2025年10月30日**

本特定服务条款（以下简称"特定服务条款"）包含适用于特定服务的补充条款，构成您或您所代表的组织、公司或其他实体（以下简称"客户"）与 LingtrueAPI 就链接到或以其他方式引用本特定服务条款的服务（如商业服务条款，以下简称"协议"）达成的协议的一部分。本特定服务条款中未定义的任何大写术语将具有协议中规定的定义。如果条款与本特定服务条款之间存在任何冲突，则以本特定服务条款为准。

## A. LingtrueAPI 工作版（团队版；企业版）

客户必须告知其用户：(i)他们正在访问一项受管理的服务产品，该产品使客户能够访问和控制客户及其用户提交给服务的数据，以及(ii)服务的使用受 LingtrueAPI 政策的约束，包括隐私政策和使用政策。客户有责任获取任何必要的用户同意并提供适用法律所要求的所有用户通知。

## B. 测试版服务

LingtrueAPI 可能提供处于预发布、测试版、预览或类似试用形式的服务（"测试版服务"）。这意味着它们不适合生产使用，并以"原样"形式临时提供。LingtrueAPI 对客户使用或依赖测试版服务不承担责任，也无义务为其使用提供任何赔偿。

## C. 微调服务

LingtrueAPI 可能提供允许客户微调或进行其他形式的模型定制的服务（"微调服务"以及由此产生的任何模型，"微调模型"），包括使用客户提供的数据（"微调材料"）。微调服务使用微调材料来生成或验证微调模型。微调材料属于客户内容。客户使用微调服务不构成违反协议中的训练禁令；但所进行的训练仅限于客户使用微调服务。

## D. 云托管服务

**概述。** LingtrueAPI 通过以下第三方管理和托管的技术环境提供某些服务：(1) Amazon Bedrock（"Bedrock"），由 Amazon Web Services, Inc. 及其关联方（"AWS"）托管和管理；以及(2) Vertex AI（"Vertex"），由 Google LLC 及其关联方（"Google"）托管和管理。AWS 和 Google 是本特定服务条款中的"云提供商"，其环境是"云平台"。客户承认并同意 LingtrueAPI 对云平台或客户从云提供商处接收的任何其他服务不承担责任，并且云平台或其他云提供商服务的变更可能对客户使用服务产生重大影响。客户仅可在遵守适用的云提供商政策及其与适用云提供商达成的协议的情况下使用服务。

**云平台上的内容。** LingtrueAPI 提供的通过云平台访问服务的技术不使 LingtrueAPI 能够访问客户在云提供商处的任何实例，包括其中包含的客户内容。

**费用。** 客户必须按 LingtrueAPI 当时的费率向适用的云提供商支付通过云平台使用服务的所有适用费用和税费，除非双方另有约定。费率更新自适用云提供商或 LingtrueAPI 发布更新后30天或客户以其他方式收到通知（以较早者为准）起生效。

## E. 开发合作伙伴计划

客户可自行决定通过启用服务的宽松数据选择加入设置（"开发合作伙伴模式"）来参与开发合作伙伴计划。如果客户启用开发合作伙伴模式，LingtrueAPI 可将客户提交给服务的数据（如客户内容）用于 LingtrueAPI 的产品和服务，包括用于训练模型。

## F. API 使用限制

客户必须遵守以下 API 使用限制：

- **速率限制：** 客户必须遵守 LingtrueAPI 指定的 API 调用速率限制
- **配额：** 客户的使用不得超过分配的配额
- **缓存：** 客户可以缓存响应，但必须遵守 LingtrueAPI 的缓存政策
- **监控：** LingtrueAPI 保留监控 API 使用的权利

## G. 数据保留

- **客户数据：** 客户数据将按照客户的保留设置进行保留
- **备份：** LingtrueAPI 将维护系统备份以确保服务连续性
- **删除：** 终止后，客户数据将按照数据处理附录进行处理

## H. 服务级别协议（SLA）

LingtrueAPI 致力于提供高可用性服务：

- **可用性目标：** 月度正常运行时间 99.9%
- **维护：** 计划维护将提前通知
- **支持：** 根据客户的计划提供技术支持

## I. 更新和修改

LingtrueAPI 可能会不时更新本特定服务条款。重大变更将提前通知客户，并在通知后30天生效。
